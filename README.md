# SpendWise - Automated UPI Cashflow & Trading Sandbox

SpendWise is a financial launchpad tailored for college students. It acts as an automated UPI cashflow manager to keep daily spending in check, while seamlessly doubling as a gamified investment academy and risk-free trading sandbox to build real-world wealth-generation skills.

## 🎯 Key Features
1. **Daily UPI Cashflow Manager:** Track daily spending, monitor remaining daily budgets, and categorize expenses.
2. **Stock & Investment Tracker:** A risk-free trading sandbox to simulate real-world investments.
3. **Investment Academy:** A learning module that teaches investment strategies across various fields.
4. **Interactive Dashboard:** A simple, easy-to-use, and responsive dashboard providing a clear overview of spending habits.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Phase 1)
* **Design:** Figma
* **Future Implementation:** JavaScript (DOM Manipulation), Node.js, Express.js, MongoDB
