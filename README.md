# SpendWise - Automated UPI Cashflow & Trading Sandbox
The Daily UPI Cashflow Manager helps users keep track of their everyday UPI transactions and manage their daily spending effectively.

### Key Features

- 💰 Track daily spending and cash flow
- 📊 Monitor the remaining daily budget
- 🧾 Record and categorize expenses
- 🎯 Set and manage daily spending limits
- 📈 Get a clear overview of spending habits
- ⚡ Simple and easy-to-use dashboard
- 📱 Responsive design for different screen sizes

### How It Helps

The cashflow manager provides users with a simple way to understand where their money is being spent. By keeping track of daily expenses and the remaining budget, users can make better spending decisions and stay within their planned limits.
